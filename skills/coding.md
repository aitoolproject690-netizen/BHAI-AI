# Coding Skill

- **Skill Name:** coding
- **Purpose:** Write, refactor, review, test, and debug code across JavaScript, React, HTML, CSS, Node.js, and other web technologies.
- **Trigger Conditions:** When user asks to implement a feature, fix bugs, refactor code, write tests, or analyze code quality.
- **Required Tools:** `github_read`, `github_update`
- **Execution Rules:**
  1. Inspect existing codebase structure before writing code.
  2. Follow existing code style and conventions without breaking working UI or features.
  3. Ensure syntax correctness and compatibility with Vite / Node.js environments.
- **Output Format:** Clean code blocks, updated file contents, and clear explanations of changes.
